# Investigation record

Use only applicable fields. Keep a short result short; do not manufacture an Issue or run identity.

- Failure / expected behavior:
- Repository, snapshot, environment and observation time:
- Existing Issue/workstream/run or none:
- Observed stage, exact command, exit status and evidence reference:
- Reproduction status and safe execution surface:
- Relevant working case / first divergent boundary:

| Hypothesis | Supporting / contradicting evidence | Discriminating check | Result |
|---|---|---|---|

- Cause status: confirmed | supported | unresolved
- Causal explanation and confidence limit:
- Failed probes/repairs already tried:
- Narrowest proposed repair or missing observation:
- Behavioral regression and expected result:
- Next operation, authority, prerequisite and stop point:
- Existing carrier/save status or continuation delta:

Do not mark a cause confirmed from timing correlation alone, call an environment blocker a behavioral test failure, or claim a repair without checking the original symptom on the repaired snapshot.
